천이도가 드러내는 것

  • 본동선은 5홉짜리 한 줄이다. 홈 → 역사 선택 → 시리즈 목록 → 시리즈 상세 → 학습 뷰어. 여기서 퀴즈와 스토어로 갈라진다. 이 축은 링크가 촘촘하고, 되돌아가기(뷰어 → 역사 선택)까지 갖춰져 있다.
  • 학습 → 구매 전환로가 3개 있다. 시리즈 상세 · 학습 뷰어 · 아웃트로가 각각 /shop/detail.html?id= 로 직행한다. 반대로 스토어에서 학습으로 오는 길은 마이페이지의 "구매한 시리즈"뿐이다.
  • 퀴즈 뱅크는 헤더에 없다. 진입로가 시리즈 상세·학습 뷰어의 CTA와, 끊긴 /topics/detail 뿐이다. 퀴즈 자체를 목적으로 온 사용자는 도달할 방법이 없다.
  • 연표가 두 계열로 갈라져 있다. 홈이 보내는 /korean/timeline 계열과, 헤더가 보내는 /timeline/timeline-bank 계열이 서로 링크되지 않는다.
  • 아카이브와 아티클은 한 줄로 이어져 있다. 이슈 시리즈 → 시리즈 보드가 유일한 연결이고, 정작 아티클 목록으로는 못 넘어간다.

끊긴 페이지 14개

  • 클러스터째 고립 주제(topics) 2개, 포럼 2개, 추천 2개. 각 클러스터 안에서는 목록↔상세가 정상 동작하는데 바깥에서 들어오는 링크가 0이다. 특히 /topics/detail은 학습·퀴즈·아티클·스토어로 뻗는 교차 허브라, 헤더에 한 줄만 넣으면 끊긴 퀴즈 뱅크와 아티클까지 같이 살아난다.
  • 학습 주변부 플래시카드 허브 · 타자 목록/연습은 뷰어와 아웃트로 어디에서도 안 부른다. 플래시카드는 뷰어가 /learn/flashcard.html?id= 로 직접 열기 때문에 허브만 남겨졌다.
  • 레거시 잔재 /learn/outro.html(뷰어 탭으로 흡수, 리다이렉트만 함), /archive/issue-detail-2026.html(사본), /history-map.html.
  • 개발용 /quiz/seed.html, /learn/chatbot_test.html — 배포 대상에서 빼도 되는 것들.

되돌아가기 점검 (2026-08-11)

  • 고침 · 다음 편으로 넘어가면 나가기가 두 단계 위로 떨어지던 문제 이전 편 카드는 &origin=을 전파하는데 다음 편 카드만 빠져 있었다. 같은 규칙을 적용했다.
  • 고침 · 퀴즈·플래시카드 왕복 후 시리즈를 잃던 문제 navigateExit()이 outro=true면 출처를 통째로 버렸다. 대신 진입 시점에 '들어왔던 목록'을 sessionStorage에 확정해 두고, 학습 흐름 안쪽 페이지(뷰어·퀴즈·보완·플래시카드·아웃트로)는 출처 후보에서 제외한다. 이슈 아카이브가 이미 쓰던 방식과 같다.
  • 고침 · 시리즈 상세의 '← 목록으로'가 목록으로 안 가던 문제 역사 선택으로 하드코딩돼 있어 ?country= 필터가 날아갔다. 목록을 거쳐 왔다는 근거(referrer 또는 직전 목록 URL)가 있을 때만 그쪽으로 보내고, 없으면 기존 폴백을 유지한다.
  • 남은 것 미국편 티저 CTA ?id=20(id 형식 불일치), 연표 상세 막다른 길, 오답 노트에서 푼 문제가 퀴즈 뱅크로 복귀하는 것, 상품 상세 breadcrumb 고정.

읽을 때 주의

  • 호스팅이 cleanUrls: true 라, /korean/series?id= 같은 확장자 없는 링크(소련편 티저)도 정상 동작한다.
  • /japanese/**, /chinese/** 는 301로 /korean 에 합쳐진다. 아웃트로·뷰어에 남은 그 링크들은 결국 역사 선택으로 떨어진다.
  • 모달·드로어(로그인, 후기 작성, 인사이트 공유, 연표 정보창)는 페이지 이동이 아니라 노드로 세지 않았다. 단, 연표 정보창 안의 "학습하기"는 실제 이동이라 그렸다.
  • 헤더·푸터·장바구니는 전 페이지 공통이라 점선으로 한 번만 그렸다. 실제로는 46개 페이지 전부에서 나가는 화살표다.
