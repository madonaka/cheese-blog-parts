# 도시 안내도 파이프라인 — 인계 문서

**이 문서를 새 채팅에 통째로 붙여 넣으면 다른 도시 지도를 같은 방식으로 만들 수 있다.**
`pipeline/` 폴더의 스크립트가 함께 들어 있다.

만든 것: 1930년 경성 전차 노선도의 시각 문법(크림 바탕 · 굵은 회색 선 · 라운드 이름표)으로
OpenStreetMap 자료를 다시 그린 도시 안내도. 평양판은 도엽 4장으로 냈다.

---

## 0. 시작하기 전에 — 이 방법이 맞는 자료인가

| 대상 | 되는가 | 비고 |
|---|---|---|
| 현재 도시 (서울·부산·도쿄·평양…) | ✅ 그대로 | OSM에 도로·시설이 있다 |
| **1920년대 경성** | ⚠️ 절반만 | OSM엔 옛 지형이 없다. §7 참조 |
| 가상 도시 | ✅ | 좌표만 만들어 주면 렌더러는 그대로 |

**핵심: 이 파이프라인은 "자료 수집"과 "그리기" 두 반쪽이다.**
역사 지도는 앞 반쪽을 다른 것으로 갈아 끼우면 뒤 반쪽은 그대로 쓴다.

---

## 1. 결과물의 구조 — 왜 여러 장인가

한 장에 다 넣으면 중심부에서 이름표가 서로 밀어내 수십 개가 사라진다.
평양에서 실측한 결과, 한 장으로는 시설 24개·도로명 31개가 통째로 빠졌다.
**축척을 달리한 여러 장으로 나누는 것이 정답이다.**

```
1. 광역 구역도    1px≈40m    구역·군 경계와 이름 + 도엽 색인(붉은 점선)
2. 시가지 전역    1px≈10m    도시 뼈대. 외곽 시설은 여기서만 보인다
3. 중심부 상세    1px≈5.6m   이면도로·골목까지
4. 특정 구역 확대  1px≈1.7m   기관이 몰린 곳. 건물 외곽선까지
```

축척비는 대략 **4배씩** 벌리면 각 장의 역할이 갈린다.

## 2. 파일 구성

```
conf.py          도엽 정의(bbox·축척·선 굵기·표기). 새 도시는 여기부터 고친다
geo.py           투영·단순화(RDP)·way 이어붙이기
layers.py        OSM JSON → 화면 좌표 (물·도로·철도·구역·시설·이면도로)
prep.py          실을 시설 고르기 (범주·등급·표기)
korean.py        문화어 → 남한 표기 (두음법칙 + 표)
zonearea.py      흩어진 선을 감싸는 면 만들기 (경내 같은 것)
render.py        SVG 본체 — 도형·이름표 자동배치
chrome.py        제목·범례·축척·방위
build_page.py    도엽들을 확대·이동 되는 HTML 한 장으로
page_template.html   그 HTML의 틀
queries/TEMPLATES.md  Overpass 질의문 모음 (bbox만 바꿔 쓰면 됨)
```

실행:
```bash
python prep.py                       # 시설 목록 + 외곽선 질의문 생성
PYMAP_VIEW=core python chrome.py     # 도엽 하나 렌더 (render.py를 끌어온다)
python build_page.py                 # 4장을 한 페이지로
```

## 3. 새 도시 적용 절차

### ① 자료 받기 (Overpass)

```
[out:json][timeout:300];
( way["highway"~"^(motorway|trunk|primary|secondary|tertiary)$"](남,서,북,동); );
out geom;
```

받을 것: 도로 / 이면도로(`residential|unclassified|living_street`) / 물
(`natural=water` 관계는 outer·inner 링을 이어 `fill-rule=evenodd`로 섬 처리) /
철도 / 구역 경계(`admin_level`) / **이름 붙은 것 전수** / 시설 외곽선.

> **이름 붙은 것 전수 조사가 제일 중요하다.**
> `nwr["name"][!highway][!waterway][!railway][!boundary](bbox); out center tags;`
> 관광 태그만 훑으면 그 도시에서 정작 중요한 게 통째로 빠진다.
> 평양 첫 판에서 노동당 청사·관저·혁명열사릉·백화원 영빈관이 전부 누락됐다.

### ② 도엽 범위 정하기 (`conf.py`)

```python
"core": dict(
    lat0=..., lat1=..., lon0=..., lon1=..., w_in=2100.0,
    title="○○ 중심부 상세도", file="citymap-core",
    keep_unnamed_tertiary=True, show_buildings=False, show_tier3=True,
    road_w={"a":16,"b":11.5,"c":7.6,"d":5}, minor_w=2.4,
    dist_fs=27, tier1_fs=15, tier2_fs=12.6, roads_first=True,
),
```

- `w_in` = 화폭 가로 px. 높이는 위경도 비율로 자동.
- 선 굵기는 축척에 비례해 키운다. 안 그러면 확대 도엽이 실오라기처럼 보인다.
- `roads_first` — 상세도는 도로명 우선, 전역도는 시설 우선. **이 한 줄이 결과를 크게 가른다.**

### ③ 시설 고르기 (`prep.py`)

`(범주, 등급, 이름)` 목록. **목록 순서가 곧 우선순위**라 자리가 모자라면 뒤부터 빠진다.

```python
PICKS = [
    ("power", 1, "조선로동당 중앙위원회"),   # 1급 = 색 박스
    ("symbol", 2, "천리마동상"),            # 2급 = 동그라미
    ("life",   3, "제2백화점"),             # 3급 = 확대 도엽에만
]
```

범주별 색 (크림 바탕에서 한 식구로 읽히게 채도를 낮춘다):

| 범주 | 색 | 기호 |
|---|---|---|
| 당·정 기관 | `#9c3226` | 박스/원 |
| 초대소·관저 | `#9c3226` | 집(⌂) |
| 외교공관 | `#2f7fa8` | 박스/원 |
| 기념·상징 | `#1b3a6b` | 박스/원 |
| 성곽·성문 | `#7a4b86` | 문(門) |
| 문화·생활 | `#1a6156` | 박스/원 |
| 교육·의료·숙박 | `#6d5326` | 박스/원 |
| 교통 | `#4a4741` | 박스/원 |

**고르는 기준은 태그가 아니라 이름값** — 그 지역 독자가 들어봤을 곳.

### ④ 렌더 → 검증 → 반복

`render.py`는 끝에 미배치 목록을 뱉는다. 그걸 보고 등급·우선순위를 조정한다.

## 4. 반드시 알아야 할 함정 (다 겪은 것들)

### 자료

1. **OSM 행정경계는 영해를 포함한다.** 국토·시 윤곽으로 쓰면 안 된다.
   북한은 해안에서 50 km 밖까지 나가고 면적이 25% 컸다(151,137 vs 120,540 km²).
   → 해안이 있는 도시는 `natural=coastline`으로 육지를 따로 만든다(§5).
2. **행정구역 소속은 기하학으로 어림하지 마라.** 중심점 판정도 경계점 과반 판정도
   이웃 군을 잘못 넣는다. `admin_level` 상위 관계의 **`subarea` 멤버 목록**이 정답.
3. **넓은 랜드마크**(공원·대학 캠퍼스·산성)를 진하게 칠하면 물처럼 보이는 덩어리가 된다.
   면적 임계값(≈1400 px²) 넘으면 옅은 면 + 테두리로.
4. **강 중심선**(`waterway=river`)을 굵게 깔면 강 폴리곤 밖으로 삐져나온 꼬리가 보인다.
   폴리곤이 완전한 큰 강은 중심선을 아예 빼라.
5. **해안선을 이을 땐 way를 뒤집지 마라.** "왼쪽이 육지"라는 방향이 곧 정보다.
   `geo.chain()`은 붙이려고 뒤집으므로 해안선엔 쓰면 안 된다.

### 도안

6. **모든 건물을 그리면 범용 OSM 지도가 된다.** 이 도안의 핵심은 *안 그리는 것*이다.
   이름 실은 시설만 실제 외곽선으로 그리고 나머지는 비운다.
7. **구역 이름은 폴리곤 내부점**(경계에서 가장 먼 지점, 격자 표본)에 앉힌다.
   외곽선 좌표 평균을 쓰면 폴리곤 밖으로 나간다.
8. **선은 생김새를 갈라라.** 도로·철도·경계가 다 회색 파선이면 아무도 구분 못 한다.
   도로=실선 / 철도=검은 선+밝은 눈금(사다리) / 경계=가는 점선.
   **그리고 범례에 반드시 넣어라.** 안 넣으면 "이 선이 뭐냐"는 질문이 온다.
9. **이름표가 남의 표를 덮지 않게** 표(글리프) 자리를 먼저 선점하고 이름표를 앉힌다.
10. **뭉친 곳은 확대 부분지도(inset)로 뺀다.** 이음선과 본도의 범위 표시를 함께.

### 표기 (한국어권)

11. **두음법칙은 어절 첫 음절에만.** 기계적으로 다 바꾸면 도로→도노, 거리→거이가 된다.
    청류대·옥류관·천리마처럼 형태소 안쪽 ㄹ은 남한도 그대로 쓴다.
    복합어 경계(혁명렬사릉→혁명열사릉)는 표로 따로 처리.
    외국 국명은 표로 먼저 바꾸고 **그 자리를 잠가야** 루마니아가 누마니아가 안 된다.
12. **표기 변환은 글자 폭 계산 전에 끝내라.** 나중에 바꾸면 이름표 상자가 어긋난다.

### 환경 (Windows)

13. **Bash 힙독이 백슬래시를 먹는다.** `'\\n'` 든 파이썬/JS는 Write 도구로 파일을 만들어라.
    조용히 깨진 코드가 생겨 원인 찾느라 오래 헤맨다.
14. **헤드리스 Chrome 캡쳐**로 결과를 눈으로 확인한다. PowerShell 도구로 돌릴 것
    (Bash는 샌드박스가 쓰기를 막는다). `--user-data-dir` 필수.
    **Windows는 창 최소 폭이 ~500px이라 390px 스크린샷은 500px 렌더의 잘린 조각이다** —
    없는 가로 넘침 버그를 쫓게 된다.
15. Overpass는 연속 대용량 질의에 제한을 건다. 실패하면 45~60초 쉬고 재시도.

## 5. 해안이 있는 도시 — 육지 윤곽 만들기

행정경계는 못 쓴다(§4-1). 해안선에서 만든다.

```
① natural=coastline 을 넉넉한 bbox로 받는다
② 0.5 km 격자에 해안선을 '벽'으로 굽는다
③ 내륙의 한 점(시청 등)에서 물을 채운다 → 닿는 칸이 육지
④ 경계를 추적해 폴리곤으로 되돌리고 Chaikin으로 다듬는다
⑤ SVG clipPath 를 겹쳐 행정경계와 교집합 → 이웃 나라가 안 칠해진다
```

사슬을 잇고 닫는 방식은 만(灣)에서 깨진다. 격자 채우기는 위상에 안 흔들린다.
`nation.py`의 `land_mask()` / `land_polygons()` 참고.

## 6. 검증 — 눈짐작 금지

| 무엇 | 어떻게 | 평양판 결과 |
|---|---|---|
| 윤곽이 맞나 | **면적을 실제 값과 대조** | 오차 +25% → +2.3% |
| 위치가 맞나 | 아는 지점 15~20곳 육지/바다·구역 판정 | 17/18 통과 |
| 라벨이 다 들어갔나 | 렌더 후 미배치 목록 출력 | 1급 0곳 미배치 |
| 보기에 어떤가 | 헤드리스 캡쳐 후 눈으로 | — |

**면적 대조가 가장 강력하다.** 좌표 몇 개로 시험하면 내가 고른 "바다"가 실은
육지인 경우가 생긴다(평양판에서 실제로 겪음). 집계 지표를 써라.

## 7. 1920년대 경성 같은 역사 지도

**OSM엔 옛 지형이 없다.** 그리기 쪽(§1~3의 도안·라벨 배치)은 그대로 쓰고,
자료 쪽만 갈아 끼운다.

### 갈 수 있는 길

**A. 현재 OSM을 바탕으로 옛 이름만 얹기** (제일 싸다)
- 사대문·궁궐·종로·청계천 등 지금도 남은 것은 OSM에 있다.
- 지금 지형 위에 옛 이름(경성부·본정·황금정…)을 표기.
- **한계: 사라진 것(경성부청·조선신궁·전차 노선)은 좌표가 없다.**

**B. 옛 지도를 좌표로 옮기기** (제대로 하려면 이것)
- 자료: 조선총독부 『경성부 시가도』, 1/10,000 지형도,
  서울역사아카이브·국토지리정보원 구지도, 규장각 소장 도면.
- 절차: 옛 지도 이미지를 현재 지도에 기준점 맞춰 얹고(georeferencing),
  전차 노선·도로·주요 건물을 좌표로 찍어 GeoJSON으로 만든다.
- 그다음은 이 파이프라인 그대로. `layers.py`가 읽는 자료만 바뀐다.

**C. 둘을 겹치기** (콘텐츠로는 이게 제일 세다)
- 현재 도로망을 옅게 깔고 옛 지형을 진하게 얹어 **"그때와 지금"**을 한 장에.

### 새 채팅에 이렇게 부탁하면 된다

> 첨부한 HANDOFF.md와 pipeline/ 스크립트를 읽고, 같은 도안으로
> 1920년대 경성 지도를 만들어줘. 자료는 [A/B/C 중 택]으로 가고,
> 옛 지도 이미지는 [출처]에서 가져올게. 도엽은 [광역/시가지/중심부] 세 장.

**역사 지도에서 특히 조심할 것**
- 지어낸 좌표를 사실처럼 그리지 말 것. 근거가 없으면 "추정"으로 명시하거나 빼라.
  (평양판에서 평양성 성벽이 OSM에 없어, 없는 선을 긋는 대신 남은 성문·누정만 표시했다.)
- 옛 지명과 현재 지명을 섞지 말 것. 어느 시점 표기인지 범례에 못 박아라.
