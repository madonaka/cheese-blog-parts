# 2026-07-30 회의 — cheesehistory.com Google Search Console 색인 오류 진단

> 참여: 치즈랩 대표, Claude
> 주제: GSC에 계속 뜨는 색인 오류(대체 페이지·리디렉션·403·404·발견됨-색인안됨)의 원인을 실제 사이트를 뜯어 진단하고, 무엇을 고쳐야 하는지 가른다

---

## 배경 (왜 이 회의를 했나)

대표가 GSC "페이지 색인 생성" 화면에서 색인 오류가 계속 뜨는 것을 보고 원인 분석을 요청. 화면상 항목이 많아(대체 페이지 21, 리디렉션 포함 8, 리디렉션 오류 7, noindex 2, 403 2, 404 1, robots 차단 1, 발견됨-색인안됨 80 등) 무엇이 진짜 문제이고 무엇이 손댈 필요 없는지 구분이 안 되는 상태였음. 실제 페이지의 canonical·리디렉션·robots·본문을 직접 확인해 판정하기로 함.

---

## 오늘 정한 것 (결론)

1. **GSC에 뜬 오류 대부분은 실제 오류가 아니라 정상 동작이거나 도메인 연결 초기의 과거 흔적 — 손댈 것 없음.**
   사이트 구조는 Blogger(Blogspot) 커스텀 도메인 + 앞단 Cloudflare. 확인 결과: "대체 페이지(21)"는 Blogger의 `?m=1` 모바일 URL이 canonical로 정리된 정상 상태, "리디렉션 포함(8)"은 apex→www 301 정상, "리디렉션 오류(7)"·"404(1)"은 지금 다시 크롤하면 전부 HTTP 200으로 정상(마지막 크롤이 도메인 연결 초기라 그때 꼬였던 흔적), "403(2)"는 글별 댓글 RSS 피드라 애초에 색인 대상 아님(무해). → 재검증만 돌리면 목록에서 빠짐.

2. **진짜 과제는 "발견됨 - 현재 색인 생성 안 됨(80건)" 하나뿐이고, 이건 콘텐츠 부실이 아니라 신생 사이트라 크롤 순번이 안 온 것.**
   해당 URL들의 "최종 크롤링 = 해당사항 없음" = 구글이 사이트맵에서 주소는 발견했으나 아직 한 번도 방문(크롤)하지 않은 상태. 실제 글(예: 고려왕조계보3)을 열어보니 제목·본문 텍스트가 충분히 들어있어 빈 페이지가 아님. 사이트맵도 제출일 2026-07-12로 최근(2주 반)이고 상태 성공·오늘 읽힘·105건 발견으로 정상. 즉 기술 결함이 아니라 시간·권위·크롤 유도의 문제.

3. **대응은 기술 수정이 아니라 크롤 유도로 간다.**
   중요한 글부터 URL 검사 → 색인 생성 요청(하루 5~10개, 한도 있음), 색인된 글·홈에서 안 된 글로 내부 링크, 외부 유입(SNS·커뮤니티), 꾸준한 발행. 색인은 2~8주에 걸쳐 점진적으로 들어오는 것으로 기대치 설정. GSC 매일 새로고침 대신 1~2주 단위로 "색인 생성됨" 증가 여부만 관찰.

4. **`{{BODY_4}}` 템플릿 토큰 누출 버그를 고쳤다.**
   인터랙티브 글 본문에 치환 안 된 `{{BODY_4}}` 문자열이 그대로 노출되던 것을 대표가 편집기에서 해당 섹션 삭제. 색인 치명타는 아니나 품질 신호에 안 좋아 정리.

## 아직 안 정한 것 (다음에, 필요해지면)

- 가계도 이미지의 구글 드라이브 호스팅(`drive.google.com/thumbnail?id=...`) 전환 여부. 이 블로그의 알맹이가 가계도 이미지인데 드라이브 호스팅은 구글 이미지 검색에 잘 안 잡히고 로딩도 불안정. 장기적으로 Blogger 자체 업로드/일반 이미지 호스팅 검토 여지.
- 인터랙티브 글의 네비게이션 위젯이 Apps Script fetch로 클라이언트 렌더링되는 구조(본문은 정적이라 무방)에 대한 SEO 영향 재점검 여부.

→ 색인 진행 추이를 1~2주 지켜본 뒤, 색인이 잘 안 붙는 글이 이미지 위주인지 등을 보고 판단.
